# OpenLearnHub Client

This is the frontend for OpenLearnHub, a modern learning platform.

## Features
- **Modern UI**: Clean, responsive interface inspired by top learning platforms.
- **Category Browsing**: Explore courses by categories with fluid animations.
- **User Dashboard**: Track enrolled courses and progress.
- **Instructor Tools**: Create and manage courses.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Redux Toolkit
- TanStack Query
- Lucide Icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```
